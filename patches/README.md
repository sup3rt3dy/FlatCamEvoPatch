# Patch archive

Historical, **already-applied** patch scripts from this fork's stability work. Nothing here is
imported or executed by the application — these are kept as a record of what was changed and why.

They previously sat in the repository root, which made the project hard to navigate.

## Superseded

The deleted-widget crash class that PATCH-3 through PATCH-8 chased one site at a time is now
handled centrally by `appGUI.GUIElements.safe_widget_call()`, which swallows only PyQt's
"wrapped C/C++ object has been deleted" `RuntimeError` and re-raises everything else. It is
applied to the `ui_disconnect()` and `set_value()` methods across the codebase, and every
`try` block operating on `.ui` widgets now catches `RuntimeError`.

`ui_safety.py` and `ui_decorators.py` were generated by `comprehensive_widget_hotfix.py` but
were never imported by the application. They were removed; use `safe_widget_call` instead.

Everything removed remains in git history.
